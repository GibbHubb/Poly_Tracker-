# Poly Tracker — tasks

The task list is **not kept here**. Poly Tracker's tickets are the `PT*` rows in the
`backlog_bandit` backlog (`BACKLOG.md`), with a plan per ticket in `plans/poly_tracker/` and a
done-log entry when each closes. A summary of what is built, in progress and next is in
[docs/product/roadmap.md](docs/product/roadmap.md).

This file used to hold the first scaffold pass's five tasks (PT-1 render saved geometry, PT-2 photo
upload with EXIF GPS, PT-3 edit and delete, PT-4 offline editing parity, PT-5 production nginx
build). All five shipped long ago, and keeping a second list beside the real one only let the two
disagree, so it was reduced to this pointer (PT37, 2026-10-21). The old text is in git history.
