# Feature PRDs

One PRD per feature. Copy [`_template.md`](_template.md) → `NN-short-name.md`, fill it before building.

| PRD | Status | Description |
|-----|--------|-------------|

## Convention

- Filename: `NN-kebab-case.md` (NN = zero-padded order it was started).
- A PRD is written **before** the feature is built and updated as it changes (see its Changelog section).
- Shipped PRDs stay here as the historical record — do not delete.
